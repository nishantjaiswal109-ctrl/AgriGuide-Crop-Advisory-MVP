The system must process localized environmental factors, field parameters, soil health metrics, and real-time operational inputs to generate highly accurate, actionable, and structured agricultural recommendations using Google Gemini AI.

You must generate all source code, database migrations, API controllers, validation schemas, UI components, and deployment configurations without using dummy placeholders, truncated functions, `// TODO` comments, or skipped boilerplate. ---

# PRODUCT GOAL
The **AI-Powered Agriculture Crop Advisory Assistant** bridges the gap between complex agronomical science and daily field operations. It enables agricultural users to submit hyper-local farm data—including location context, soil texture, NPK balance (Nitrogen, Phosphorus, Potassium), pH levels, moisture indicators, historical irrigation practices, micro-climate weather conditions, crop varieties, and growth stages—to receive precise, real-time AI-driven advisory plans.

### Key Value Propositions:
- **Precision Agronomy:** Delivers tailored fertilization, pest control, irrigation, and harvesting recommendations grounded in real-time field data.
- **Early Disease & Risk Mitigation:** Predicts pest outbreaks, fungal risks, and climate stress with actionable prevention and intervention protocols.
- **Economic & Yield Optimization:** Combines crop yield projection models with market timing suggestions to maximize operational profitability.
- **Multi-Tenant Farm Management:** Provides secure cloud workspaces for farm managers to track multiple plots, archive historical advisories, and compare multi-season field performance.

# MANDATORY FEATURES

1. **User Authentication & Multi-Tenant Access:**
   - Email/password authentication and OAuth integration via Supabase Auth.
   - Profile management with customizable user roles (Farmer, Agronomist, Extension Worker, System Admin).
   - Secure session handling with client-side context persistence and server-side JWT verification.

2. **Interactive Farm & Field Profile Manager:**
   - Multi-farm and multi-plot management interface.
   - Field metric tracking: soil type, pH, NPK balance, moisture index, acreage, elevation, and irrigation setup.

3. **Multi-Stage Advisory Request Engine:**
   - Step-by-step wizard to build complex advisory queries.
   - Input categories: Soil Metrics, Weather Context, Crop Details, Growth Stage, Symptom/Observation Logs (with optional visual metadata).
   - Real-time client-side Zod validation before submission.

4. **AI-Powered Advisory Processing Core:**
   - Server-side invocation of `@google/genai` SDK using `gemini-2.5-pro` for deep agronomical reasoning and `gemini-2.5-flash` for rapid initial triage.
   - Strictly enforced structured JSON outputs using Gemini's native `responseSchema`.
   - Comprehensive fallback strategies with graceful degraded-mode user feedback.

5. **Dynamic Advisory Dashboard & Visualizations:**
   - Tabbed view for actionable insights: Immediate Action Items, 14-Day Irrigation Schedule, Fertilizer Calculator, Pest/Disease Risk Heatmap, and Financial Projections.
   - Interactive charts (using Recharts) for soil nutrient balances and multi-week risk trends.
   - Historical advisory archive with search, filtering by crop/stage, and side-by-side comparative analysis.

6. **Export & Sharing Hub:**
   - One-click PDF report generation for field workers.
   - Export to JSON/CSV for integration with third-party farm management software.
   - Unique shareable advisory links with time-bound access tokens.

# TECHNOLOGY REQUIREMENTS

### Frontend Architecture
- **Framework:** React.js (v18+) with Vite or Next.js (App Router) using TypeScript in strict mode.
- **Styling:** Tailwind CSS with Shadcn UI component primitives and Lucide React icons.
- **State Management & Data Fetching:** `@tanstack/react-query` (v5) for async server state, standard React Context for local UI session state.
- **Forms & Validation:** `react-hook-form` integrated with `@hookform/resolvers/zod` and `zod`.
- **Data Visualization:** `recharts` for nutrient, moisture, and trend visual analytics.

### Backend Architecture
- **Runtime:** Node.js (v20+ LTS) with Express.js (TypeScript) or Next.js Route Handlers / Server Actions.
- **Validation:** Zod schemas applied universally to request bodies, route parameters, and environment variables.
- **AI Integration:** `@google/genai` SDK (official Google Gen AI SDK) enforcing structured responses via `responseSchema` and system instructions.

### Database & Security Architecture
- **Database Engine:** Supabase PostgreSQL with `pgvector` enabled for vector search and historical similarity matching.
- **ORM / Query Builder:** Supabase JS Client (`@supabase/supabase-js`) with auto-generated TypeScript types.
- **Authorization & Security:** Row Level Security (RLS) policies on all tables tied to `auth.uid()`, strictly isolated API keys, and server-side execution of AI generation calls.
